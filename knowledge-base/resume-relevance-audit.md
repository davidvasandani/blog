Keep three judgments separate: relevance to the target role, strength of source evidence, and chronology/ownership. A highly relevant planned fix is still planned. A merged change is not necessarily enabled or verified in production. A low relevance score does not mean the work lacked value.

Freeze source versions and inventory every bullet/event before scoring. Record URL access failures even when HTTP returns 200: preview capability shells contain no source content. Preview lease metadata can identify the originating workspace without proving that its rendered content matches a committed snapshot. Keep both facts explicit.

Use effective promotion dates and the phase described by each bullet. Senior Manager took effect February 23, 2026; the earlier reporting-line change and later announcement are separate events. A project envelope spanning multiple roles does not invalidate a correctly attributed milestone. Older resume claims outside the recent timeline are uncorroborated by that timeline, not disproven. Personal implementation and workplace adoption need distinct provenance.

For the Netflix content-promotion/distribution role, the core is hands-on API integration, structured troubleshooting, targeted reusable fixes, stakeholder education, practical AI use and manual unblock work. Media/metadata ingestion is a useful bonus. Generic infrastructure cost savings should not displace specific partner-support evidence. Demonstrate Python or Java AND SQL explicitly; infrastructure tools or database names are not proof of proficiency. Personal content pipelines can bridge domains without implying professional media-partner experience.

Use stable source IDs and an explicit crosswalk. Overlapping project and incident records are not independent achievements. Preserve numerical definitions: locations can include labs; requeued work is not completed work; affected transactions and extra charges are different counts. Later verification can resolve an earlier snapshot limitation without making either record false.

Generate every readable format from the same assessments, including all source limitations. Independent review caught a Markdown renderer that omitted caveats present in HTML/JSON; test for caveat parity as well as counts, score bounds, source fidelity and references. Keep detailed private assessments in the hiring repository. Any later resume wording change still requires `/voice`.
