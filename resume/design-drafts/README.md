# Resume design drafts

15 visual treatments created with the canvas-design skill. Each is a three-page US Letter PDF with selectable text, embedded fonts, and contact links. All resume wording and facts are preserved from `../David_Vasandani_CV.yaml`.

## Review

- [Comparison booklet](00-design-comparison.pdf): five pages, three designs per page.
- [Contact sheet](00-contact-sheet.png): all 15 first pages.
- [Complete set](00-all-15-resumes.pdf): 45 pages, bookmarked by design.
- [Design philosophies](DESIGN-PHILOSOPHIES.md).

## Individual PDFs

| Design | Direction |
| --- | --- |
| [01. Swiss Precision](01-swiss-precision.pdf) | An asymmetric grid turns hierarchy into a clear visual rhythm. A cobalt square establishes a single point of emphasis. |
| [02. Literary Ledger](02-literary-ledger.pdf) | Centered serif typography and hairline rules evoke the measured authority of a carefully printed journal. |
| [03. Midnight Panel](03-midnight-panel.pdf) | A deep blue field gives the opening a strong silhouette; the body returns to generous white space. |
| [04. Signal Rail](04-signal-rail.pdf) | A narrow vermilion rail creates a constant orientation point, recalling an annotated field notebook. |
| [05. Architect Folio](05-architect-folio.pdf) | Fine registration lines and numbered sections borrow the discipline of architectural drawings. |
| [06. Quiet Authority](06-quiet-authority.pdf) | A sculptural serif name floats above an almost invisible structure, giving the content room to breathe. |
| [07. Forest Index](07-forest-index.pdf) | A pale green index column creates a steady left boundary and a generous, uninterrupted reading column. |
| [08. Modern Gazette](08-modern-gazette.pdf) | A compact masthead and double rules translate the confidence and economy of editorial print. |
| [09. Blue Notes](09-blue-notes.pdf) | A thin vertical line and small nodes make chronology visible without turning achievements into a chart. |
| [10. Warm Modernism](10-warm-modernism.pdf) | Warm paper and an offset block of terracotta create a grounded composition with humane, open typography. |
| [11. Monochrome Frame](11-monochrome-frame.pdf) | A precise perimeter and boxed masthead make the page feel complete, deliberate, and self-contained. |
| [12. Plum Register](12-plum-register.pdf) | A split masthead balances serif identity against a compact contact register; plum rules unify the two. |
| [13. Industrial Grid](13-industrial-grid.pdf) | Monospaced headings and tabular section markers suggest operational precision while keeping prose easy to read. |
| [14. Azure Margin](14-azure-margin.pdf) | An extended azure edge gives the sheet a recognizable silhouette, balanced by a quiet open masthead. |
| [15. Copper Signature](15-copper-signature.pdf) | A fine serif signature and a short copper rule create a restrained personal identity with careful spacing. |

## Validation

All 15 PDFs were checked for three pages, complete source content after whitespace normalization, and text inside the page boundaries. First-page previews and page-two/page-three review sheets were visually inspected. No resume wording, source YAML, website publishing configuration, or other service was changed.
