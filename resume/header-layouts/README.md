# Five resume header layouts

Open `index.html` for all five layouts. The file includes the fonts and works offline. Print or save PDF produces one layout per page. The active Industrial Grid template is unchanged.

## 01. Clean rows

A smaller name and two fixed contact rows. Location, email, and website stay together; social profiles get their own row.

## 02. Split header

Name and role on the left, contact details on the right. Each item has its own line, so nothing wraps by accident.

## 03. Contact grid

Six labeled cells align the contact details. Every profile has a clear place, including the longer Mastodon address.

## 04. Centered header

A centered name and role above three short rows. The links read as groups instead of one continuous line.

## 05. Separate profiles

Core contact details sit beside the name. A narrow profile rail below separates social links from the information a recruiter needs first.
