# Audit model
Source: id, URL/path, retrieval date/status, SHA-256, repository revision, limitations.
Criterion: stable code, description, posting section.
Inventory item: stable ID, kind, source ID/locator, verbatim source text/title, dates, original confidence where present.
Assessment: item ID, integer score 0–5, criterion codes, rationale, limitations, recommended use, related resume/timeline IDs. Score anchors are ordinal, not a weighted measure of candidate ability.
Finding: category (chronology, corroboration gap, domain gap, qualifier), affected IDs, evidence and next action.
Contract: every inventory ID has exactly one assessment; no dangling references; original source fields are immutable; generation and checks require no credentials or network.
